# 🧾 בוט הקבלות

שולחים צילום של קבלה לקבוצת וואטסאפ ייעודית — הבוט קורא אותה, כותב שורה מסודרת ב-Google Sheets, ועונה בקבוצה מה בדיוק הוא הבין.

```
📸 צילום בקבוצה
      ↓
   הורדה  →  קריאה ב-AI  →  שמירת התמונה  →  שורה בגיליון
      ↓
✅ "נקלט — רמי לוי · 4.8.2026 · 87.40 ₪ · שורה 12"
```

מה שה-AI לא הצליח לקרוא נשאר **ריק ומסומן** — הבוט אף פעם לא ממציא נתון שלא הופיע על הקבלה.

---

## מה זה עולה

| רכיב | עלות |
|---|---|
| חיבור לוואטסאפ | 0 ₪ — מכשיר מקושר, בלי API של מטא |
| קריאת הקבלות (Gemini) | 0 ₪ במסלול החינמי. קבלה = תמונה אחת + תשובה קצרה |
| Google Sheets | 0 ₪ |
| הרצה על המחשב שלך | 0 ₪ |

הדבר היחיד שצריך להשיג הוא **מפתח Gemini חינמי**. אין מנוי ואין כרטיס אשראי.

## הגדרה — פעם אחת

### שלב 0 · התקנה

```bash
cd receipts-bot
npm install
cp .env.example .env
```

עכשיו פותחים את `.env` וממלאים אותו לפי השלבים הבאים.

---

### שלב 1 · מפתח ה-AI

1. נכנסים ל-<https://aistudio.google.com/apikey>
2. **Create API key** → מעתיקים
3. ב-`.env`:

```
GEMINI_API_KEY=המפתח-שהעתקת
```

---

### שלב 2 · הגיליון

1. יוצרים גיליון חדש ב-Google Sheets. לא צריך לבנות כותרות — הבוט יכתוב אותן לבד.
2. מעתיקים את המזהה מתוך הכתובת:

```
https://docs.google.com/spreadsheets/d/[[[ זה המזהה ]]]/edit
```

3. ב-`.env`:

```
GOOGLE_SHEET_ID=המזהה-שהעתקת
GOOGLE_SHEET_TAB=הוצאות
```

---

### שלב 3 · חשבון שירות של Google

זה נשמע מפחיד ולוקח 4 דקות. הרעיון: יוצרים "משתמש רובוט" של גוגל, ומשתפים איתו את הגיליון — בדיוק כמו שמשתפים עם עמית לעבודה. אין מסך התחברות ואין טוקן שפג תוקף.

1. <https://console.cloud.google.com/> → יוצרים פרויקט חדש (או בוחרים קיים)
2. **APIs & Services → Library** → מחפשים **Google Sheets API** → **Enable**
3. **APIs & Services → Credentials → Create Credentials → Service account**
   - שם: `receipts-bot` → **Create and continue** → **Done**
4. לוחצים על החשבון שנוצר → לשונית **Keys** → **Add key → Create new key → JSON**
   - יורד קובץ JSON. **זה סוד — לא לשלוח לאף אחד ולא להעלות לגיטהאב.**
5. פותחים את ה-JSON ומעתיקים ל-`.env`:

```
GOOGLE_SERVICE_ACCOUNT_EMAIL=מתוך השדה  client_email
GOOGLE_PRIVATE_KEY="מתוך השדה private_key — כולל המרכאות, ובשורה אחת עם ה-\n כמו שהם"
```

6. **החשוב ביותר:** חוזרים לגיליון → **שיתוף** → מדביקים את כתובת ה-`client_email` → הרשאת **עורך** → שיתוף.

> בלי שלב 6 הבוט יקבל שגיאת הרשאה. זו הטעות הכי נפוצה כאן.

---

### שלב 4 · הקבוצה בוואטסאפ

1. פותחים בוואטסאפ **קבוצה חדשה** — רק אתה בפנים. קוראים לה למשל "קבלות".
2. מריצים:

```bash
npm run groups
```

3. סורקים את ה-QR מהטלפון: **וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר**.
4. מודפסת רשימת הקבוצות. מעתיקים את השורה של קבוצת הקבלות אל תוך `.env`:

```
RECEIPTS_GROUP_ID=120363012345678901@g.us
```

---

### שלב 5 · מריצים

```bash
npm start
```

ושולחים צילום קבלה לקבוצה. תוך כמה שניות תחזור תשובה.

## הטבלה

ארבע עמודות. זהו.

| A · תאריך | B · סכום כולל | C · מספר חשבונית | D · הוזן במערכת |
|---|---|---|---|
| 03/08/2026 | 494.00 ₪ | 0038412 | ☐ |
| 28/07/2026 | 132.00 ₪ | 1177243 | ☑ |

**עמודה D היא תיבת סימון אמיתית.** ברגע שמסמנים אותה — כל השורה נצבעת בירוק והטקסט מאפיר, כך שרואים במבט אחד מה כבר הוזן במערכת של הארגון ומה עוד מחכה. הבוט מגדיר את זה לבד בפעם הראשונה: תיבות הסימון, כלל הצביעה, פורמט תאריך ישראלי, פורמט שקלים, וכותרת קפואה.

הבוט **אף פעם לא נוגע בעמודה D** — היא רק שלך.

### הטיפ

זו הנקודה שדורשת תשומת לב: **טיפ במזומן לא מודפס על הקבלה**, אז אין דרך לקרוא אותו מהתמונה.

- טיפ שמופיע על הקבלה (שירות / תשר מודפס) — כבר כלול בסכום, לא צריך לעשות כלום.
- טיפ שהשארת במזומן — **כתוב אותו כהערה יחד עם התמונה**, למשל `טיפ 50`. הבוט יוסיף אותו לסכום ויראה לך את החישוב:

```
💰 494.00 ₪   (444.00 ₪ + 50.00 ₪ טיפ)
```

וזה מה שייכנס לעמודה B — 494, הסכום שבאמת יצא לך מהכיס.

## פרטיות ובטיחות

- **הבוט קורא קבוצה אחת בלבד.** הסינון הוא השורה הראשונה במאזין: כל הודעה שלא מגיעה מ-`RECEIPTS_GROUP_ID` נזרקת מיד, לפני שנקרא בכלל מה כתוב בה.
- `ONLY_FROM_ME=true` (ברירת מחדל) — גם בתוך הקבוצה, רק תמונות ששלחת אתה.
- הקובץ `.env` וכל תיקיות החיבור מוגנים ב-`.gitignore` ולא עולים לגיטהאב.
- הקבלות עצמן נשמרות אצלך (תיקייה מקומית או Supabase שלך). התמונה נשלחת ל-Google Gemini לצורך הקריאה — בדיוק כמו כל שירות OCR בענן. אם יש לך קבלות שאסור שיצאו מהארגון, אל תשלח אותן לכאן.
- החיבור לוואטסאפ הוא **מכשיר מקושר לא רשמי** (whatsapp-web.js), כמו שאר הפרויקט. זה נוגד את תנאי השימוש של מטא ויש סיכון קטן לחסימה.

## שמירת התמונות

ברירת המחדל היא `STORAGE=local` — התמונות נשמרות בתיקייה `receipts/` והקישור בטבלה הוא נתיב מקומי.

אם הבוט ירוץ בענן (Railway) הדיסק נמחק בכל הפעלה מחדש, ואז כדאי:

```
STORAGE=supabase
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
SUPABASE_BUCKET=receipts
```

צריך ליצור ב-Supabase → Storage דלי בשם `receipts` ולסמן אותו **Public** (אחרת הקישור בטבלה לא ייפתח).

## הרצה קבועה ב-Railway

הבוט רץ מהמחשב שלך כברירת מחדל. כדי שיעבוד תמיד, גם כשהמחשב כבוי:

1. **דחוף את הקוד לגיטהאב** (הקובץ `.env` לא עולה — הוא ב-`.gitignore`)
2. ב-Railway: **New Project → Deploy from GitHub repo** → בחר את הריפו
3. **Settings → Root Directory** → `receipts-bot`
4. **Variables** — העתק את כל התוכן של `.env` המקומי. שים לב:
   - **בלי מרכאות** סביב הערכים — Railway לוקח אותן כחלק מהערך ושובר את המפתח
   - `GOOGLE_PRIVATE_KEY` הוא היוצא מן הכלל: הוא כן צריך את המרכאות, כי יש בו `\n`
   - הוסף `WA_SESSION_PATH=/app/.wwebjs_auth` ו-`STORAGE=supabase` (דיסק מקומי נמחק בכל דיפלוי)
5. **Settings → Volumes → New Volume** ב-`/app/.wwebjs_auth`
   > בלי זה — כל דיפלוי מנתק את הוואטסאפ ודורש QR מחדש.
6. **Generate Domain**, ואז פתח את הכתובת — אמור להחזיר `{"ok":true,...}`
7. סרוק QR פעם אחת: הרץ מקומית `npm run groups`, סרוק, ואז העתק את תיקיית `.wwebjs_auth` — או פשוט הרץ פעם ראשונה עם הלוגים פתוחים ב-Railway וסרוק משם

**עלות:** הבוט מריץ Chromium, שצורך ~700MB-1GB RAM. זה בערך $5 לחודש בתוכנית הבסיסית של Railway.

## תקלות נפוצות

| מה רואים | מה זה |
|---|---|
| `Google auth 400: invalid_grant` | ה-`GOOGLE_PRIVATE_KEY` נשבר. שים אותו במרכאות כפולות, בשורה אחת, עם `\n` כמו שהם |
| `Sheets append 403` | לא שיתפת את הגיליון עם ה-`client_email` בהרשאת עורך (שלב 3.6) |
| `Sheets append 404` | `GOOGLE_SHEET_ID` שגוי |
| `הדלי "receipts" לא קיים` | צריך ליצור אותו ב-Supabase Storage, ציבורי |
| הבוט לא מגיב לכלום | `RECEIPTS_GROUP_ID` ריק או שגוי. הרץ `npm run groups` שוב |
| `⚠️ RECEIPTS_GROUP_ID ריק — מצב גילוי` | תקין. שלח הודעה בקבוצה והמזהה יודפס בלוג |
| קבלה ישנה לא נקלטה | הבוט מתעלם מהודעות בנות יותר מ-24 שעות. אפשר לשנות עם `CATCHUP_HOURS` |
| `♻️ את הקבלה הזו כבר קלטתי` | אותה תמונה בדיוק נשלחה פעמיים. זו הגנה, לא תקלה |

