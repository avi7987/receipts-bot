קבלות ישר לטופס

מעלים צילום קבלה לתיקייה בדרייב — היא נקראת לבד ונכנסת לגיליון שלך, ובטופס ההוצאות לחיצה אחת ממלאת הכול, כולל הצילום.

לפני שממלאים

  1. תיקייה בדרייב, ובתוכה גיליון ריק.

    Google Drive ← חדש ← תיקייה. נכנסים אליה ← חדש ← Google Sheets. לא כותבים בגיליון כלום.

  2. שיתוף התיקייה עם השירות, בהרשאת עורך.

    קליק ימני על התיקייה ← שיתוף ← מדביקים את הכתובת. אם גוגל מציעה לשלוח הודעה — אפשר לבטל.

    __SA_EMAIL__
  3. מפתח AI משלך.

    aistudio.google.com/apikey ← Create API key. חייבים להיות מחוברים לחשבון הגוגל שלך — הוא קורא עד 20 קבלות ביום, רק שלך.

הרשמה

בודק את התיקייה, הגיליון והמפתח ומכין את הגיליון — עד חצי דקה

לא מצליח לגרור?

ב-Edge: Ctrl+Shift+O ← קליק ימני ← הוסף דף ← שם: מילוי הוצאות ← בכתובת מדביקים. הטקסט ארוך מאוד — זה תקין.

מכאן
  1. מעלים קבלות לתיקייה. אחרי כמה דקות הן מופיעות בגיליון שלך.
  2. משלימים בגיליון את התאים הכתומים.
  3. בטופס ההוצאות מסמנים את תיבת ההצהרה, לוחצים על הסימנייה, ובסוף Save as Draft.

שמור/י את הדף הזה? לא צריך. אם הסימנייה תלך לאיבוד — נרשמים שוב עם אותה תיקייה ואותו מפתח, ומקבלים אותה מחדש.

השירות קורא רק את התיקייה ששיתפת וכותב רק לגיליון שבתוכה. הסימנייה ממלאת ושומרת כטיוטה — ההגשה נשארת בידיים שלך.
